# Разработка проверочного листа по безопасности

## Категории данных
1. Публичные данные:
    - адреса и время работы офисов продаж
    - список жилых комплексов
    - доступные к покупке объекты недвижимости
    - стоимость объектов
    - наличие текущей брони
2. Внутренние данные
    - данные о работе внутренних систем
    - внутренние инструкции для менеджеров по продажам
    - отчеты о капитальном ремонте
3. Конфиденциальные данные
    - персональные данные клиентов
    - персональные данные собственников
    - максимальный размер дисконта на объект
    - тарифы ЖКХ конкретной управляющей компании
    - стоимость проведенных сделок
    - факты и стоимость бронирований
4. Секретные данные
    - платежные данные клиентов и собственников
    - данные для регистрации в Росреестре
    - данные по настройкам систем безопасности, управления освещением и другими функциями
    - соглашения о неразглашени NDA

## Риски

1. Публичные данные - риск искажения данных. В случае несанкционированного изменения публичных параметров объектов возможны жалобы и незначительные репутационные риски

2. Внутренние данные:
    - Утечка данных о работе внутренних систем, что облегчит дальнейший поиск уязвимостей
    - Потеря всех данных этой категории, в случае удаления данных мошенниками нарушит операционные процессы компании
    - Искажение данных - в такой ситуации будут приниматься неправильные решения командой менеджеров по продажам

3. Конфиденциальные данные:
    - Утечка персональных данных клиентов или скрытых параметров формирования стоимости/дисконта могут привести к нарушению закона о 152-ФЗ, а также репутационным рискам
    - Потеря всех данных этой категории, в случае удаления данных мошенниками нарушит операционные процессы компании
    - Обесценивание данных - например, фактическая стоимость сделок, тарифы и размер дисконта расркывают стратегию компании, что приводит к потере конкурентных преимуществ

4. Секретные данные:
    - Утечка платежных данных приведет к имиджевым рискам и последующему банковскому мошенничеству на основе этих данных
    - Утечка закрых данных Росреестра приведет к санкциям и штрафам со стороны государства
    - Утечка данных "умного дома" приведет к потенциальному взлому квартир
    - Искажение платежных данных приведет к выплатам на счета мошенников

## Оценка рисков

| Категория | Риск | Влияние |
|-|-|-|
| Публичные | Искажение | Незначительный |
| Внутренние | Утечка | Незначительный |
| Внутренние | Потеря | Значительный |
| Внутренние | Искажение | Значительный |
| Конфиденциальные | Утечка | Значительный |
| Конфиденциальные | Потеря | Значительный |
| Конфиденциальные | Обесценивание | Значительный |
| Секретные | Утечка | Критический |
| Секретные | Искажение | Критический |
